Tento web. Mindmapa bez backendu, kterou píšete přímo úpravou souborů na disku a regenerujete jedním Python skriptem (`bin/gen-tree.py`).

Listy stromu jsou `.md` s YAML frontmatterem. Větve mohou být veřejné, sdílené odkazem, zamčené heslem nebo zpoplatněné (až bude napojený backend).

## Soubory projektu

- [index.html](/projects/fakan-cz/index.html) — splash page (klikni *play* v okně pro náhled v iframe)
- [style.css](/projects/fakan-cz/style.css) — barvy a typo
