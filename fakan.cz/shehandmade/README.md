# She made it
Katalog hezkých výrobků, které vyrobila ručně a s láskou.

## Homepage
Kategorie výrobků:
* Sladké zákusky
* Dorty
* Andílci
* Panenky
* ...

## Seznam
S filtrem podle kategorie. S náhledem na výrobek - obrázek, název, krátký popis.

## Detail
Detail výrobku s detailními fotkami, popisem, cenou a možností objednání.

## Kontakt
Fotka autorky, jméno, e-mail, --telefon--, odkaz na ..., ..., ...

Kontaktní formulář (může otevřít email) se sekcí "Co mne zaujalo", která se doplní z toho, co uživatel na webu označil jako zajímavé.
