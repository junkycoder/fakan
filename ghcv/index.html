Jak to funguje

  1. Připojte GitHub — stačí uživatelské jméno. Načteme veřejná repa a profil.
  2. Doplňte pár věcí — tagline, stack, web, tón, jazyk. Pole předvyplníme.
  3. Zkopírujte prompt — sestavíme ho na míru vašim datům.
  4. Vlepte odpověď AI — živý náhled markdownu a stažení README.md.

Poslední krok: nahrát na GitHub

  1. Založte si repo se stejným názvem jako váš username (např. username/username) a zaškrtněte „Add a README”.
  2. Nahraďte obsah README.md staženým souborem.
  3. Commit — profilové README se objeví nahoře na vašem GitHub profilu.
